# Diese Library: OnkyoAVR  

- Diese Library dient zur Anbindung von Pioneer / Onkyo AV Receivern an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um das ISCP Protokoll in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung zu ergänzen.
